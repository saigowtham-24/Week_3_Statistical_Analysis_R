# Week 3: Statistical Analysis and Predictive Modeling using R

## Objective
Explore the Titanic passenger dataset, perform hypothesis tests, and compare Logistic Regression and Random Forest classifiers for predicting survival.

## Repository structure
- `statistical_analysis_week3.R` — complete R analysis workflow.
- `data/` — dataset file used by the project. The R script can download the public Titanic CSV if absent.
- `plots/` — preview plots plus charts regenerated by the R script.
- `outputs/` — descriptive statistics, hypothesis tests, model metrics, predictions, and diagnostics summaries.
- `screenshots/` — add screenshots captured from your own RStudio execution.
- `Week_3_Statistical_Analysis_Report.docx` — detailed report.

## How to run
1. Install R and RStudio.
2. Open this project folder in RStudio.
3. Open `statistical_analysis_week3.R`.
4. Run the script from the project root. It installs missing required packages and downloads the Titanic CSV if needed.
5. Check `plots/` and `outputs/` for the generated results.
6. Capture genuine screenshots from RStudio and save them in `screenshots/`.

## Method
- Stratified 80/20 train/test split.
- Repeated 5-fold cross-validation (3 repeats) for model tuning/training.
- Chi-square tests for sex/class association with survival.
- Wilcoxon rank-sum test for age distributions by survival.
- Shapiro-Wilk tests on samples to assess normality.
- Logistic Regression and Random Forest compared on held-out data using accuracy, precision, recall, specificity, F1, and ROC-AUC.
